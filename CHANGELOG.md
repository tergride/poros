# Changelog

`script\release_windows.ps1` releases the newest section: its text becomes the GitHub release and what Poros shows under "What's new". Both language parts are required.

## 0.1.0

<!-- ru -->
### Новое
- Первая версия Poros: портативный клиент для Windows на основе Throne.
  - Простой режим для повседневной работы и расширенный со всеми настройками.
  - Мастер первого запуска, пресеты маршрутизации и подписки отдельными группами.
- Работает одновременно с Throne: у Poros свои порты и адреса TUN.
- Обновляется сам: новая версия скачивается в фоне и ставится после перезапуска. Автообновление можно выключить в настройках.
- Интерфейс на русском и английском, по умолчанию язык системы.

<!-- en -->
### New
- The first version of Poros, a portable Windows client based on Throne.
  - A simple mode for everyday use and an advanced mode with every setting.
  - A first-run wizard, routing presets, and subscriptions as separate groups.
- Runs next to Throne: Poros has its own ports and TUN addresses.
- Updates itself: a new version downloads in the background and installs after a restart. Automatic updates can be turned off in the settings.
- The interface is in Russian and English, and follows the system language by default.
